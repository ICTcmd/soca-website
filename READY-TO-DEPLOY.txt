========================================
🚀 DEPLOY TO GITHUB & VERCEL:
========================================

STEP 1: Initialize Git
-----------------------
git init
git add .
git commit -m "SOCA Website 2026 with video and 127 slides"

STEP 2: Create GitHub Repository
---------------------------------
1. Go to: https://github.com/new
2. Name: soca-website-2026
3. Public repository
4. Don't add README
5. Create repository

STEP 3: Push to GitHub
-----------------------
git remote add origin https://github.com/YOUR_USERNAME/soca-website-2026.git
git branch -M main
git push -u origin main

(Replace YOUR_USERNAME with your actual GitHub username)

STEP 4: Deploy to Vercel
-------------------------
1. Go to: https://vercel.com
2. Login with GitHub
3. Click "Add New Project"
4. Import "soca-website-2026"
5. Click "Deploy" (use all defaults)
6. Wait 2-3 minutes
7. Your site is LIVE! 🎉

Your URL: https://soca-website-2026.vercel.app
