   2. Run these commands:

      git init
      git add .
      git commit -m "SOCA Website 2026"
      git remote add origin https://github.com/YOUR_USERNAME/soca-website-2026.git
      git push -u origin main

   3. Go to vercel.com
   4. Import your GitHub repo
   5. Click Deploy
